1. AI、資料與機器學習的共同語言

來源：L1 p.7–17、p.35–45、p.47–77；L3-I p.7–10。

1.1 AI、ML、DL 是什麼關係

人工智慧（Artificial Intelligence, AI）是讓機器具備推理、知覺、學習與決策等能力的廣泛領域。機器學習（Machine Learning, ML）透過資料與經驗改善表現；深度學習（Deep Learning, DL）使用多層神經網路學習表徵。可記作 DL ⊂ ML ⊂ AI。AI 也可以用人工規則，不必然需要訓練。

傳統程式設計由人提供規則，資料經規則得到結果；監督式 ML 從資料與目標輸出找規則。適合 ML 的情境是有可學的規律、有相關資料，但很難人工明列規則，例如語音辨識。若已有簡單且精確的公式，未必需要 ML。

1.2 把問題寫成數學

x ∈ X：輸入，例如一封信的詞頻向量
 y ∈ Y：目標，例如 Spam 或 Ham
D = {(x₁,y₁), …, (xₙ,yₙ)}：訓練資料
f：未知的理想規律；g：演算法從資料學得的假設
目標：讓 g 在未來未見資料上接近 f

分類（classification）預測離散類別；迴歸（regression）預測連續數值。分群（clustering）沒有事先給定正確類別，要發現資料結構。分群編號本身沒有語意：把 cluster 0 與 1 對調，群的成員沒變，就仍是同一分群。

訓練表現與泛化（generalization）不同。把所有訓練樣本背熟，可能仍無法預測新樣本。應先定義任務、輸入、輸出與衡量方式，再挑演算法。

1.3 資料型態

型態特性例子與陷阱
Nominal 名目只有類別，無自然大小次序郵遞區號、學號；數字外觀不代表距離有意義
Ordinal 次序可排序，間距未必相等滿意度：低、中、高
Interval 區間差值有意義，零點非絕對零攝氏溫度；20°C 不是 10°C 的兩倍熱
Ratio 比率有真零點，比例有意義長度、重量
Discrete 離散有限或可數個值詞出現次數、班級人數
Continuous 連續理論上可取區間中的實數身高、時間

一筆資料稱 sample / instance / data object；一個描述欄位稱 feature / attribute / dimension。標籤是要預測的答案，不能把未來才知道的答案偷偷放入輸入。

1.4 哲學與推論：有效不等於前提為真

L1 強調反覆問「為什麼」。論證 valid 代表若前提為真，結論必然成立；sound 還要求前提本身為真。例如「所有有標籤資料都適合某模型；這批資料有標籤；所以適合該模型」的推論形式可以有效，但第一個前提過強，因此不健全。考試回答模型選擇時，要說出資料與假設的關係，不能只說某方法很熱門。

1.5 訓練、驗證、測試

  • Training：估計模型參數，例如 NN 的權重。
  • Validation / Dev：選超參數與模型，例如 k、樹深度、SVM 的 C、停止 epoch。
  • Test：選擇完成後估計最終泛化能力。

資料洩漏（data leakage）：使用了預測時不可能知道的資訊，或讓評估資料影響訓練／選擇。例如先用全資料算標準化平均，再做交叉驗證；正確方法是在每一 fold 的訓練部分擬合前處理，再套到該 fold 的驗證部分。PCA、補值、特徵選擇也遵守同一原則。

2. 分群：k-means、k-medoids、階層式與 DBSCAN

來源：L2 p.3–88。考古 Q5 直接考 k-means；其他方法同樣是講義重要內容。

2.1 距離、中心、半徑與直徑

歐氏距離 d(x,z) = √Σⱼ(xⱼ−zⱼ)²。若某欄位以萬元、某欄位以公分記錄，量級大的欄位可能主宰距離。常用 z-score：x'ⱼ = (xⱼ−μⱼ)/sⱼ；μ、s 應從訓練資料估計，常數欄位需另行處理。

Centroid 是平均點，不必是原資料；medoid 是群內的一筆真實資料，通常選使群內距離總和最小的點。

講義 L2 p.13 的 radius 與 diameter 使用均方距離定義：

μ = (1/N) Σᵢ xᵢ
R = √[(1/N) Σᵢ ‖xᵢ−μ‖²]
D = √[(1/(N(N−1))) Σᵢ Σⱼ ‖xᵢ−xⱼ‖²]，N > 1
因此 D² = 2N/(N−1) × R²，並非一般的 D = 2R。

有的教材將 diameter 定義為最大兩點距離，與這裡不同；遇到題目先看定義。

2.2 k-means 的目標與步驟

J = Σⱼ₌₁ᵏ Σₓ∈Cⱼ ‖x−μⱼ‖²  （SSE / inertia）
1. 選 k 個初始中心。
2. Assignment：每個點歸到最近中心。
3. Update：每一群的中心改為該群所有點的平均。
4. 重複 2–3，直到分群不變或改善很小。

固定中心時，指派到最近群會使 J 不增加；固定分群時，平均數使平方誤差最小。因此交替操作讓目標不增加，但 不保證找到全域最佳解，因為群指派與中心一起最佳化是非凸問題。初始化不同，可能到不同局部解。

自編手算例：資料 {0,2,8,10}，k=2，初始中心 0、8。第一次指派為 {0,2}、{8,10}，中心更新成 1、9；再次指派不變，SSE = 1+1+1+1 = 4。

為何 mean 是最佳中心？對群 C 的 Σ(xᵢ−μ)² 微分，得到 2Nμ−2Σxᵢ=0，因此 μ=平均數。多維情形逐座標相同。

2.3 初始化與限制

  • 多次隨機重啟：各跑到收斂，保留 SSE 最小者。
  • k-means++：第一點隨機選，後續以到最近已選中心的 距離平方 D(x)² 為抽樣權重，讓種子傾向分散。不是每次直接挑最遠點，也不保證全域最佳。
  • 指定 random seed 只讓結果可重現，本身不保證品質更好。

k-means 需要預先指定 k，偏好由歐氏距離與平均中心描述的緊密群。遇到離群值、大小與密度差異大或同心圓，可能很差。平方距離會放大極端值對中心的影響；空群出現時通常需重設中心。

每次指派約 O(nkd)，總共 t 輪約 O(tnkd)。講義 O(tkn) 將維度 d 當常數。k 增加時最小可達 SSE 不會增加，所以不能單純以「SSE 最低」選 k。

2.4 k-medoids 與 PAM

k-medoids 用真實資料點作代表，常以距離總和為成本。PAM：選 k 個 medoids → 指派最近點 → 嘗試 medoid 與非 medoid 對調 → 接受降低成本的交換 → 重複。相較平均中心，對極端離群值通常較穩健，也能搭配非歐氏距離；代價是交換搜尋昂貴。講義每輪約 O(k(n−k)²)。CLARA 使用抽樣改善規模問題，CLARANS 使用隨機化搜尋。

2.5 階層式分群

Agglomerative（凝聚式、AGNES）由每個點一群開始，反覆合併最近的兩群。Divisive（分裂式、DIANA）從全部一群開始向下拆。Dendrogram（樹狀圖）記錄合併層次，在特定高度切開可得到分群，不必在建立整棵樹前指定 k。

Linkage兩群距離特徵
Singlemin d(x,z)容易 chaining，靠細鏈連成大群
Completemax d(x,z)偏好緊密群，受極端點影響
Average所有跨群點對距離的平均折衷，別誤算成中心距離
Centroid兩群平均中心的距離與 average linkage 不同
Medoid兩群代表資料點的距離代表點須屬於資料

主要限制是距離矩陣通常需要 O(n²) 空間，常見基本方法時間也很高；貪婪合併通常不能撤銷。BIRCH 以 CF-tree 摘要子群；CURE 用多個分散代表點並向中心縮。

2.6 DBSCAN：先分點，再擴張群

Nε(p) = {q ∈ D : d(p,q) ≤ ε}
Core：|Nε(p)| ≥ MinPts
Border：不是 core，但位在至少一個 core 的 ε 鄰域內
Noise：既非 core，也非 border

此處採常見且與鄰域集合式一致的約定：包含 p 自己，且使用 ≥。若試題另有規定，按試題計數。講義 p.35 的文字「more than」與其他頁「at least」不一致，不能混用。

演算法從未處理的核心點開始，沿密度可達關係擴張。邊界點可以加入群，但 不能只靠邊界點繼續把群串接出去。某點早期被暫標為 noise，後來若被核心點涵蓋，應改為 border；一開始非 core 不代表最後一定是 noise。

自編例：一維 {0,0.1,0.2,0.4,1.2}，ε=0.21、MinPts=3，包含自己。0、0.1、0.2 都至少有三點，為 core；0.4 只有自己與 0.2，為 border；1.2 為 noise。前四點成一群。

  • q 從 p 直接密度可達：p 必須是核心點，q 在其鄰域。
  • 密度可達：可沿一串直接可達的點抵達，通常不對稱。
  • 密度相連：存在 o，使 p、q 都從 o 密度可達，為對稱關係。

DBSCAN 不需先給 k、能找非球狀群且標出 noise；但 ε 與 MinPts 敏感，單組參數難同時處理差很大的密度。邊界點若接觸兩群，歸屬可能依走訪順序而異。不要把講義的「one scan」解讀成保證 O(n)：鄰域查詢成本仍取決於資料結構與維度。

2.7 分群品質與選 k

a(i)：i 到同群其他點的平均距離
b(i)：對每個其他群算平均距離，再取最小值
s(i) = [b(i)−a(i)] / max(a(i),b(i))

Silhouette 大致介於 −1 與 1：接近 1 表示群內近、群外遠；接近 0 表示群邊界；負值表示平均而言更靠近別群。b(i) 不是最近一個點的距離，也不是到最近中心的距離。單點群常約定 s=0；全部只分一群時無法按一般定義比較另一群。

有真實類別時：Homogeneity 要求每一群內的樣本來自同一真實類別；Completeness 要求同一真實類別的樣本集中在同一群。它們不要求預測群編號與真實標籤數字完全一致。Elbow 是額外常見補充：觀察 SSE 隨 k 增加的下降幅度，在邊際改善變小處取捨。

3. 高維資料與 PCA

來源：L2 p.98–123。此章不在提供的考古計算大題中，但屬講義範圍。

3.1 維度災難

高維空間中資料稀疏，取得相同覆蓋程度需要更多樣本；無關維度會稀釋有用訊號。在某些分布與距離條件下，最近與最遠距離的相對差異變小，因此距離的辨識能力下降。最近鄰索引也可能退化。不是所有高維資料都無法學習，低內在維度或合適表徵仍可有幫助。

Feature selection 挑原本的欄位；PCA 是 feature extraction，把多個欄位線性組合成新軸。PCA 不看標籤，保留大變異不等於保留最有分類能力的方向。

3.2 PCA 的完整步驟

給 n 筆 d 維資料：
1. 平均 μ = (1/n)Σxᵢ，中心化 x̃ᵢ = xᵢ−μ。
2. 視量尺決定是否再標準化；中心化與標準化是不同操作。
3. S = (1/n)Σ x̃ᵢ x̃ᵢᵀ，計算共變異數矩陣。
4. 解 S vⱼ = λⱼ vⱼ；λ₁ ≥ λ₂ ≥ … ≥ 0，vⱼ 為正交單位向量。
5. 取前 k 個方向，W = [v₁ … vₖ]（d×k）。
6. z = Wᵀ(x−μ)（k×1），重建 x̂ = μ+Wz。

有些講義把每個方向排成列，因此寫 z=Wx；只是 W 的定義不同，必須檢查矩陣維度。共變異數若用 1/(n−1)，特徵值會整體縮放，主方向與解釋變異比例不變。

3.3 為什麼是最大特徵值的方向

單位向量 v 上的投影為 z=vᵀx̃，變異數 Var(z)=vᵀSv。最大化 vᵀSv，限制 vᵀv=1，令 L=vᵀSv−λ(vᵀv−1)。一階條件 2Sv−2λv=0，所以 Sv=λv；目標值正好等於 λ，因此選最大特徵值對應方向。第二主成分需另加與第一方向正交的限制，依序選後續特徵向量。

第 j 成分 explained variance ratio = λⱼ / Σᵣλᵣ
累積保留比例 = (λ₁+…+λₖ) / Σᵣλᵣ

自編例：S=[[3,1],[1,3]]。特徵值 4、2，方向 (1,1)/√2、(1,−1)/√2。保留第一成分得到 4/6≈66.7% 變異。中心化點 (2,0) 的 z=√2，重建 (1,1)。PCA 方向正負號可互換，表示的子空間相同；重複特徵值時，該子空間內的正交基也不唯一。

3.4 限制與判斷

PCA 是線性、無監督方法，易受特徵尺度與離群值影響，不能保證保留類別資訊。當各欄單位不同時，先標準化常有意義，但不是所有任務都必須標準化；應依哪些尺度有實際意義決定。若 λ₁…λ₆ 的比例為講義四捨五入的 0.45、0.18、0.13、0.12、0.07、0.04，前四項約 88%；總和 0.99 是近似造成，不要硬解讀成完整機率缺失。

4. 決策樹：從熵到剪枝

來源：L3-I p.12–47；考古 Q1、Q6.1。

4.1 決策樹怎麼學

內部節點測試特徵、分支對應結果、葉節點輸出類別；根到葉的路徑是一條 AND 規則，多條正類路徑以 OR 組合。ID3 使用資訊增益，從上而下貪婪選擇，不會保證整棵樹全域最小。

停止條件包括節點已純、沒有剩餘有效特徵、樣本太少或達深度限制。混合標籤的葉節點常用多數決，平手需有既定規則。足夠深的樹可表示有限布林輸入上的任何布林函數；單一線性分類器不能表示 XOR。

4.2 Entropy 與 Information Gain

H(S) = −Σ𝚌 p𝚌 log₂p𝚌，約定 0 log₂0 = 0
H(S|A) = Σᵥ [|Sᵥ|/|S|] H(Sᵥ)
IG(S,A) = H(S)−H(S|A)

二元類別各半時 H=1 bit，純節點 H=0。二元 H(1/4)=H(3/4)≈0.811278；H(1/3)≈0.918296；H(2/5)≈0.970951。資訊增益衡量知道 A 後對標籤不確定性平均減少多少。

自編例：父節點 4 正 4 負，A 分為 (3正,1負) 與 (1正,3負)。父熵 1；子熵各 0.811278；加權熵 0.811278；IG=0.188722。若子群大小不同，要用不同權重，不能一律平均。

整體的加權條件熵不高於父熵，IG≥0，但 IG 可以等於 0；個別子節點的熵可能比父節點高。例如父節點 9正1負，切出一個1正1負的子節點，其熵從約0.469升到1。因此「每次切割熵都嚴格下降」不是普遍真命題。

4.3 Gain Ratio 與 Gini

準則公式或選擇注意
Information gain選最大 IG偏好多值特徵，例如每人唯一 ID
Gain ratioIG / SplitInfo正規化分支資訊量；SplitInfo=0 時不可直接除
GiniG=1−Σp𝚌²常用於 CART，二元分類最大 0.5

SplitInfo(A)=−Σᵥqᵥlog₂qᵥ，qᵥ=|Sᵥ|/|S|。SplitInfo 用分支大小，H(S) 用類別比例，兩者不能替換。分割後 Gini 也依樣本數加權，選減少最多或加權 Gini 最小的切割。C4.5 以 gain ratio 為代表，CART 通常採二元切割。

4.4 連續特徵與重複測試

連續特徵可排序，考慮相鄰不同值的中點 t，測試 A≤t / A>t，再比較增益。同一路徑可以先測 age≤60，再在左分支測 age≤30，這能區分年齡區間。

若是基本 ID3 對離散屬性一次依完整取值分支，走到子節點後該屬性已固定，再測同一屬性沒有資訊。因此「重複屬性冗餘」須限定情境，並非所有決策樹通則。

4.5 過度擬合與剪枝

Overfitting：訓練誤差很低，但未見資料表現差。樹太深可能把噪聲、罕見樣本與離群點都切成規則。

  • Pre-pruning：提早停止，例如限制最大深度、最小葉樣本數、最小增益，或檢定切割是否有顯著關聯。限制太強也可能欠擬合。
  • Post-pruning：先長樹，再刪除沒有帶來泛化收益的子樹，常以驗證資料或複雜度懲罰挑選。

卡方檢定（L3-I p.38–44）：虛無假設為特徵與標籤獨立，期望次數 Eᵣ𝚌=該列總數×該欄總數/總樣本數，χ²=Σ(O−E)²/E，自由度 (r−1)(c−1)。講義出席表 [[30,10],[10,20]] 的 χ²≈12.15（講義先四捨五入得到約12.13），df=1，大於 α=0.05 的臨界值3.84，可拒絕獨立假設。這表示有統計關聯，不等同證明出席造成及格。

4.6 手算作答模板

  1. 計父節點各類數量，先寫 H(parent)。
  2. 逐一列候選特徵每一分支的 (正,負)。
  3. 計每一子群熵，再以分支樣本比例加權。
  4. 算 IG；若平手，明說平手並給選擇規則。
  5. 畫樹時標示切割屬性、邊的值、各節點類別分布。
  6. 若還要下一層，在該子群內重新計算，不能沿用全資料 IG。

5. Naive Bayes：機率、條件獨立與平滑

來源：L3-I p.49–59；考古 Q2、Q6.3。

5.1 Bayes 與 MAP

P(y|x) = P(x|y)P(y)/P(x)
ŷ = argmax_y P(y)P(x|y)
Naive 假設：P(x₁,…,x_d|y) = ∏ⱼ P(xⱼ|y)
log score(y) = log P(y) + Σⱼ log P(xⱼ|y)

Prior 是看到 x 前的類別機率；Likelihood 是在類別給定時觀察 x 的機率；Posterior 是看到 x 後對類別的機率。只比較類別時可省略所有類別共同的 evidence P(x)，但若要求真正 posterior，就要再正規化。

Naive Bayes 是 generative：建模 P(x|y) 與 P(y)，進而得到 P(y|x)。Discriminative 方法如 logistic regression，直接建模 P(y|x) 或決策邊界。

5.2 三種輸入模型不能混用

模型特徵表示類別條件機率
Categorical NB每個欄位有若干離散值(該值在類別內計數+α)/(該類樣本數+α×該欄可能值數)
Multinomial NB詞頻 c_w；重複詞重複計入(詞 token 計數+α)/(該類總 token 數+α|V|)
Bernoulli NB每詞有／無，二元(有該詞的文件數+α)/(該類文件數+2α)

Bernoulli NB 還會把「沒出現」的詞以 1−P(w|y) 計入；Multinomial NB 使用詞頻，沒出現的詞次數為0，因此其冪次為0。不應在 Multinomial NB 把分母直接當文件總數。

Gaussian NB（L3-I p.55）適合連續特徵：對每個類別與特徵估 μ、σ²，以常態密度代入。密度值不是單點事件機率；連續分布在精確某個實數的機率是0。

5.3 Laplace smoothing

沒有平滑時，只要一個條件機率為0，整個乘積就變成0。平滑給每個可能值 α 個偽計數：α=1 稱 add-one / Laplace。分子加 α，分母要同時加 α 乘上可能值數，才能維持總和為1。

自編 Multinomial 例：詞彙 {a,b,c}，某類計數 {4,1,0}，α=1；機率為 5/8、2/8、1/8。不是分母 6，也不是只平滑沒出現的 c。未知詞是否納入 <UNK> 需由建模約定決定，不能臨時只改某一類的詞彙大小。

5.4 文件分類與 log

對詞頻向量 c_w，score(y)=P(y)∏_wP(w|y)^{c_w}。例如文件 a a b，a 的機率需平方。使用 log 可把乘法轉加法，避免小數連乘下溢；log 的底數只要一致，類別排序不變。熵題指定 log₂，則不能隨意換底不補係數。

若兩個 unnormalized scores 為 s₁、s₂，posterior 為 s₁/(s₁+s₂) 與 s₂/(s₁+s₂)。有共同的 multinomial 組合係數時，分類可略去；完整文件機率才需按事件定義保留。

5.5 條件獨立不是無條件獨立

NB 假設「給定 y 之後」特徵互相獨立。兩個詞整體常一起出現，不必然代表條件獨立失敗；須看每一類內仍是否有依賴。若高度相關詞在同類內仍相關，NB 可能重複計算同一證據而過度自信，影響 posterior 校準與決策；但不保證每次都分錯，分類排序仍可能正確。

訓練正確率100%也不代表 P(y正確|x)=1，只要正確類別分數最高就能判對。

6. k-NN、泛化與集成方法

來源：L3-II p.4–6；L3-I p.61–82。

6.1 k-NN 是 lazy learning

k-NN 保存訓練樣本，預測時才計距離找鄰居。分類用多數決，迴歸常用平均；加權版本給近鄰更大權重，例如 1/(d+ε)。它不需要先訓練一個全域參數模型，但預測與儲存可能昂貴。

若用訓練資料本身當查詢、包含自己且沒有重複矛盾點，k=1 的訓練誤差為0。這不是 leave-one-out 表現，也不代表 test 誤差為0。

k 的變化邊界與泛化傾向
k 小邊界細碎；低 bias、高 variance，容易受噪聲影響
k 大邊界平滑；較高 bias、較低 variance，可能忽略小群

以上是一般趨勢，不是對所有資料的嚴格定理。選 k 要用驗證集／CV。k-NN 自然可處理多類別，但偶數 k、相同距離或票數平手要指定規則；標準化對距離特徵很重要。

6.2 欠擬合、過度擬合與 bias / variance

Underfitting 是模型過簡或最佳化不足，training 與 validation 都差。Overfitting 是訓練好、驗證相對差。增加模型容量通常可降低可達訓練誤差，但也可能加大泛化風險。

平方誤差的典型理論分解為 Bias² + Variance + 不可約噪聲（補充）：bias 是平均模型與真函數的差，variance 是訓練資料變動造成的模型變動。不是「訓練誤差=bias、測試誤差=variance」。

6.3 Bagging、Boosting、Random Forest

方法怎麼產生多模型如何合併核心理解
Baggingbootstrap 有放回抽樣，各自訓練分類投票、迴歸平均通常降低高變異模型的 variance
Boosting依序訓練，後續補前面的錯誤加權組合讓弱模型逐步組成強模型，可能追逐噪聲
Random Forestbagging 樹，加上每節點隨機特徵候選投票／平均降低樹與樹之間的相關性

Bootstrap 每次通常抽 n 次，但因有放回，不代表每個樣本都出現。以標準 bootstrap 而言，特定樣本未被抽到的機率為 (1−1/n)^n，n 大時約 e⁻¹≈36.8%（補充）；可作 out-of-bag 評估。

講義五個模型各正確率0.6的例子：若各模型對同一樣本的判斷獨立且正確率相同，多數決正確率為 Σᵣ₌₃⁵ C(5,r)0.6ʳ0.4⁵⁻ʳ=0.68256。僅知道平均正確率0.6不足以推出此結果；若五個模型錯在完全相同樣本，多數決仍只有0.6。集成需要多樣性。

6.4 多類別與不平衡

m 類的 One-vs-Rest 需要 m 個分類器；One-vs-One 需要 m(m−1)/2 個。OvR 常取最高分，OvO 常投票。k-NN、決策樹、softmax 本身可自然處理多類別。

不平衡資料中，全猜多數類也可能 accuracy 很高。可考慮類別權重、oversampling、undersampling、調整決策閾值，並用 precision / recall / F1 等評估。重採樣應只在訓練資料內做，不能先對全部資料複製再切分，以免同一筆出現在 train 與 test。

7. SVM：邊界、margin 與 kernel

來源：L3-II p.8–48；考古 Q4。這章的「距離」與「表示尺度」一定要分清楚。

7.1 線性決策函數

g(x)=wᵀx+b；ŷ=sign(g(x))，y∈{−1,+1}
決策邊界：wᵀx+b=0
w 是邊界的法向量；b 決定位移
functional margin：γ̂ᵢ=yᵢ(wᵀxᵢ+b)
signed geometric margin：γᵢ=γ̂ᵢ/‖w‖，w≠0
普通點到平面距離：|wᵀx+b|/‖w‖

分對時 γᵢ>0，分錯時 γᵢ<0；落在邊界為0。資料集 margin=minᵢγᵢ。若全都分對，這等於最近點到邊界的距離。

將 (w,b) 乘上 c>0，邊界與分類不變，functional margins 乘 c，geometric margins 不變，因分子分母一起乘 c。只把 w 乘 c 而不改 b，通常會改變邊界。c<0 邊界雖相同但正負預測翻轉。

7.2 Hard margin 與兩種 margin 定義

在線性可分時，把表示尺度規範為最近點滿足 yᵢ(wᵀxᵢ+b)=1：

min ½‖w‖²
subject to yᵢ(wᵀxᵢ+b) ≥ 1，所有 i
單側幾何 margin = 1/‖w‖
兩條支撐平面 wᵀx+b=+1、−1 的完整帶寬 = 2/‖w‖

題目可能把 margin 用來指半邊距離，也可能指完整帶寬；必須照定義回答。考古 Q4 用 min geometric margin，採單側距離。

支援向量是決定最佳邊界的訓練點。非退化的 hard-margin 解中通常位於 yᵢg(xᵢ)=1。嚴格 dual 定義是 αᵢ>0；退化情況下某些恰在 margin 上的點可能 αᵢ=0。不要把任意分隔線最近的點都稱為「已求得最佳 SVM 的支援向量」。

7.3 Soft margin 與 C

不可分時 hard-margin 約束不可行，需引入鬆弛變數：

min ½‖w‖² + C Σᵢξᵢ
subject to yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ，ξᵢ≥0
等價懲罰形式：½‖w‖² + C Σᵢ max(0,1−yᵢg(xᵢ))

C 大代表更重視減少 margin violation，通常更貼合訓練資料；C 小容許較多違反，較重視小權重與較寬 margin。不是「C 越大，正則化越強」。

在最小必要鬆弛量的理解下：ξ=0 表示在 margin 上或外側；0<ξ<1 表示分對但進入 margin；ξ=1 表示在決策邊界；ξ>1 表示分錯。Soft SVM 最小化 hinge penalty 與權重的折衷，不是直接最小化 0–1 誤分類數。

7.4 Dual 與 kernel trick

max_α Σᵢαᵢ − ½ΣᵢΣⱼ αᵢαⱼ yᵢyⱼ K(xᵢ,xⱼ)
soft-margin constraints：0≤αᵢ≤C，Σᵢαᵢyᵢ=0
g(x)=Σᵢ αᵢ yᵢ K(xᵢ,x)+b

Hard margin 的 dual 沒有 α≤C 上界。線性時 w=Σαᵢyᵢxᵢ。

由 primal 推 dual 的骨架：寫 L=½wᵀw−Σαᵢ[yᵢ(wᵀxᵢ+b)−1]；對 w、b 設導數0，得到 w=Σαᵢyᵢxᵢ、Σαᵢyᵢ=0；代回得到 dual。KKT 的互補條件 αᵢ[yᵢg(xᵢ)−1]=0，使不在 margin 的點可有 α=0。

若存在映射 φ，使 K(x,z)=φ(x)ᵀφ(z)，可用 kernel 值直接取代高維內積。訓練與預測不必明列每一個高維特徵；高維中線性的分隔面，在原空間可形成非線性邊界。Kernel 不是「任意相似度都可」，需符合有效內積 kernel 的性質。

7.5 二次 polynomial kernel 展開

K(x,z)=(x₁z₁+x₂z₂+c₀)²
c₀=0：x₁²z₁² + 2x₁x₂z₁z₂ + x₂²z₂²
一組映射 φ(x)=(x₁², √2 x₁x₂, x₂²)

c₀=1：再加 2x₁z₁ + 2x₂z₂ + 1
一組映射 φ(x)=(x₁², √2 x₁x₂, x₂², √2 x₁, √2 x₂, 1)

只有二次交叉特徵 x₁x₂ 並不能完整代表整個二次 kernel，還包含平方項。√2 使特徵內積的係數恰好等於展開式。此處 c₀ 是 kernel 常數，與 soft-margin 的懲罰 C 是不同概念，雖然考古題用同一字母 C。

RBF kernel 為 exp(−γ‖x−z‖²)，γ 控制相似度衰減；γ 很大時邊界可很局部，需與 C 一起調整（補充）。用更豐富的 kernel 不保證資料一定可分，尤其同一 x 若有矛盾標籤，確定性特徵映射仍不能消除矛盾。

7.6 Perceptron（考古公式表延伸）

當 y(wᵀx+b) ≤ 0：
w ← w+ηyx；b ← b+ηy

Perceptron 找能分對的邊界，不以最大 margin 為目標；線性可分時在適當條件下會收斂，不可分時可能持續更新。與 SVM 的最佳化目標不同。

8. 模型評估、交叉驗證與 ROC

來源：L3-II p.51–65；考古 Q6.6。

8.1 混淆矩陣先固定軸

實際＼預測PositiveNegative
PositiveTPFN
NegativeFPTN
Accuracy=(TP+TN)/(TP+FP+FN+TN)
Precision=TP/(TP+FP)  → 宣告正的樣本，有多少是真的正
Recall=TP/(TP+FN)     → 真正為正的樣本，有多少被找到
Specificity=TN/(TN+FP)
FPR=FP/(FP+TN)=1−Specificity
F1=2PR/(P+R)=2TP/(2TP+FP+FN)

F1 不使用 TN，且是調和平均。通常介於 P 與 R 之間；若 P>R>0，則 R<F1<P。分母為0時要依題目或套件約定處理，不能直接當正常除法。

自編例：TP=30、FP=10、FN=20、TN=40，P=0.75、R=0.6、F1=2/3、Acc=0.7。別把 precision 分母誤寫成 TP+FN。

8.2 不平衡、閾值與錯誤成本

1000 筆資料只有10筆正例，全猜負例 accuracy=99%，但 recall=0。若漏掉正例代價高，需關注 recall；若誤報代價高，需關注 precision，但兩者都應在任務背景下權衡。

對分數分類器降低正類閾值，會讓預測正例集合擴大，因此 TPR 與 FPR 都不減少；precision 不保證單調提高或降低。閾值選擇需用驗證資料。

8.3 Holdout、k-fold、LOOCV

Holdout 是一次切分。k-fold CV 將資料分 k 份，每次 k−1 份訓練、1份驗證，平均 k 次結果；不是每次重用同一份驗證。Stratified CV 盡量保留類別比例。LOOCV 是 k=n，每次留一筆，計算成本較高。

若樣本存在病人、使用者或時間相依，應按群組或時間切分，不能讓同一個體的近似資料跨集合。這是泛化評估補充，不代表課程額外演算法範圍。

8.4 ROC / AUC

ROC 的橫軸 FPR，縱軸 TPR=Recall，掃過閾值形成曲線。左上角較理想；隨機排序的基準對角線 AUC 約0.5，完美排序為1。AUC 衡量排序能力，不是某一閾值下的 accuracy。ROC 不直接呈現 precision；不平衡情況可另看 PR curve（補充）。

9. 神經網路：參數、前向與反向傳播

來源：L4 p.15–59、p.61–101；考古 Q3、Q6.4。

9.1 一個神經元與一層網路

單元：z=Σⱼ wⱼxⱼ+b，a=f(z)
一層：zˡ=Wˡaˡ⁻¹+bˡ，aˡ=fˡ(zˡ)，a⁰=x
若前層有 m 個單元、此層 n 個：W 為 n×m，b 為 n×1

z 是 activation 前的線性輸入；a 是 activation 後的輸出，兩者不可混稱。Bias 平移決策面；input nodes 本身一般沒有待訓練參數。

全連接 m→n 共有 mn 個連接權重與 n 個 bias，總計 (m+1)n。多層則加總每一層。ReLU、sigmoid、一般 softmax 本身沒有可訓練參數；不要多算。

9.2 Activation Functions

函數值域導數與特性
Sigmoid σ(z)=1/(1+e⁻ᶻ)(0,1)σ'(z)=σ(z)(1−σ(z))；兩端飽和、導數趨0
tanh(z)(−1,1)1−tanh²(z)；零中心，仍會飽和
ReLU=max(0,z)[0,∞)z>0 導數1、z<0 導數0；z=0不可微
Leaky ReLU=max(αz,z)，0<α<1實數負側保留斜率 α，連續；0處通常不可微
Linear f(z)=z實數導數1，常用迴歸輸出
Softmax每個分量(0,1)、總和1互斥多類別機率；分量互相耦合

若每層都只有線性／仿射轉換，多層仍可合併成單層仿射轉換，不能靠加深表達一般非線性。

「連續」與「可微」不同：ReLU 在0連續但不可微，可採約定的次梯度進行訓練；step 函數在跳點不連續，且其他地方導數0，會使梯度學習困難。考古的 Leaky Step 是分段常數，與 Leaky ReLU 不同。

Maxout（L4 p.23–24）取多個仿射值的最大值，學得分段線性函數；ELU 負側使用指數形式，使負側輸出較平滑。重點先掌握 sigmoid / tanh / ReLU，再看其他變體。

9.3 輸出與 loss 要配對

任務常見輸出Loss
數值迴歸Linear平方誤差／MSE
二元分類單一 sigmoidBinary cross entropy
互斥多類分類K 維 softmaxCategorical cross entropy
平方誤差：L=½(y−t)² → ∂L/∂y=y−t
BCE：L=−[t log p+(1−t)log(1−p)]
Softmax：pₖ=exp(zₖ)/Σⱼexp(zⱼ)
CE：L=−Σₖtₖ log pₖ；one-hot 時等於 −log p_true
Softmax + CE：∂L/∂zₖ=pₖ−tₖ
Sigmoid + BCE：∂L/∂z=p−t

MSE 若題目不用 ½，微分多出2；若對 n 筆取平均，梯度需除 n。比較答案前先確認 loss 定義。

Softmax 可將所有 logits 同減 max(z) 避免 exp overflow，機率不變。多標籤問題的多個標籤可同時成立，一般用多個 sigmoid，不應直接套互斥 softmax（補充）。

9.4 Forward Pass 範例

自編小網路：x=(1,2)，hidden 兩個 sigmoid；第一個權重 (1,−1)、bias=0，第二個權重 (0.5,0.5)、bias=−0.5；linear output 權重 (2,1)、bias=0。

z₁=1×1−1×2=−1；a₁=σ(−1)≈0.268941
z₂=0.5×1+0.5×2−0.5=1；a₂=σ(1)≈0.731059
y=2a₁+a₂≈1.268941
若 t=1，L=½(1.268941−1)²≈0.036165

前向時逐層保留 z、a，反向會用到。不要先對每一中間值只留兩位小數，否則誤差可能逐步放大。

9.5 Chain Rule 與 Backpropagation

反向傳播是有效率地重用中間梯度，並依 chain rule 算每個參數的偏導；更新參數是 optimizer 的工作。

對單一隱藏層、線性輸出與平方 loss：

hⱼ=f(zⱼ)，zⱼ=Σᵢwⱼᵢxᵢ+bⱼ
y=Σⱼvⱼhⱼ+b_out，L=½(y−t)²
δ_out = y−t
∂L/∂vⱼ = δ_out hⱼ
∂L/∂b_out = δ_out
δⱼ = δ_out vⱼ f'(zⱼ)
∂L/∂wⱼᵢ = δⱼ xᵢ
∂L/∂bⱼ = δⱼ

對前例 t=1：δ_out≈0.268941；∂L/∂v₁=0.268941²≈0.072329；hidden1 的 δ₁≈0.268941×2×0.268941×0.731059≈0.105754；所以 ∂L/∂w₁₁≈0.105754、∂L/∂w₁₂≈0.211508。

若一個節點通往多個下游節點，需要把所有路徑的貢獻加總：

定義 δˡ=∂L/∂zˡ
δˡ = [(Wˡ⁺¹)ᵀδˡ⁺¹] ⊙ f'(zˡ)
∂L/∂Wˡ = δˡ(aˡ⁻¹)ᵀ
∂L/∂bˡ = δˡ
⊙：逐元素相乘

必須先用同一次 forward 對應的舊權重算完所有梯度，再一起更新。不能先改輸出權重，再用已改過的值往回算 hidden 梯度。

9.6 Gradient Descent 的方向

θ_new = θ_old − η∇L(θ_old)，η>0

梯度為正就讓參數減少；梯度為負就讓參數增加。這是在目前點的局部下降方向，學習率太大仍可能跨過谷底、震盪或發散。

一階 Taylor 展開：L(θ+Δ)≈L(θ)+∇LᵀΔ。選 Δ=−η∇L，變化近似 −η‖∇L‖²≤0，說明負梯度在小步長時為下降方向。這不能保證任意 η 都使實際 loss 下降。

9.7 深度、初始化與梯度問題

深層網路能重用階層化模組，例如像素→邊緣→物件部件→物件，對某些函數比非常寬的淺層網路更有效率。Universal approximation 的直覺是在適當 activation 與條件下，足夠寬的單隱藏層可在緊緻區間上任意逼近連續函數；不代表精確表示所有函數、不保證訓練找得到、不保證泛化。

多層相乘的小導數可造成 vanishing gradients；ReLU 在正側導數1能緩解這種局部衰減，但負側導數0仍可能造成 dead ReLU，其他權重因子也可讓梯度消失／爆炸。

同層 hidden units 若全部同樣初始化，收到相同梯度就會一直學同樣的特徵，破壞多單元的作用。通常隨機且尺度適當地初始化權重；bias 設0常可行。講「所有權重設0不好」不等於「任何參數都不能為0」。

10. 深度學習實務：最佳化、正則化、診斷

來源：L4 p.95–101；L5 p.4–39；考古 Q6.5。

10.1 Batch、SGD、Mini-batch 與 epoch

方法一次更新看多少樣本特性
Batch GD所有 n 筆全資料梯度，單次成本高
SGD 狹義1 筆更新頻繁、梯度噪聲較大
Mini-batchB 筆兼顧平行化與更新頻率

一個 epoch 通常指整份訓練資料走過一次；iteration / step 指一次參數更新。若 n=1000、batch size=128，保留最後不足 batch 時，每 epoch 為 ceil(1000/128)=8 steps；若丟掉最後不足部分，為7 steps。Mini-batch 平均梯度為 (1/B)Σ∇Lᵢ，最後一批若大小不同需依實際定義處理。

10.2 最佳化器比較

以下公式是逐元素運算；g_t=∇L(θ_t)，ε 是穩定用的小正數。

Momentum（補充基本形式）：m_t=βm_(t−1)+(1−β)g_t；θ←θ−ηm_t
Adagrad：G_t=G_(t−1)+g_t²；θ←θ−ηg_t/(√G_t+ε)
RMSprop：v_t=ρv_(t−1)+(1−ρ)g_t²；θ←θ−ηg_t/(√v_t+ε)
Adam：m_t=β₁m_(t−1)+(1−β₁)g_t
      v_t=β₂v_(t−1)+(1−β₂)g_t²
      m̂_t=m_t/(1−β₁ᵗ)，v̂_t=v_t/(1−β₂ᵗ)
      θ←θ−ηm̂_t/(√v̂_t+ε)

Adagrad 累積所有歷史平方梯度，某些座標的有效步長可能越來越小；RMSprop 用移動平均緩解無限累積；Adam 結合一階與二階動量，偏差修正處理零初始化造成的初期低估。Adadelta 使用近期梯度與近期更新量的 RMS 比率來調整步長，常不需另手動設全域初始學習率，但仍有超參數。

AdamW 把 weight decay 與自適應梯度更新分離；對 Adam 類最佳化器，直接把 L2 項混進梯度通常不等於 decoupled weight decay。這是解讀 L5 的 Adam / AdamW 脈絡補充，不需死背軟體 API。

10.3 Learning-rate schedule

Exponential decay：η_t=η₀γᵗ，0<γ<1
Cosine（單一衰減週期）：
η_t=η_min+½(η_max−η_min)[1+cos(πt/T)]，0≤t≤T

Cosine 的起點 η_max、終點 η_min。有 warm restarts 的變體會重新提高學習率；不要把講義示意的重啟曲線與任何單一 cosine scheduler API 畫等號。Optimizer 決定如何用梯度，scheduler 決定學習率如何隨步數／epoch 變化。

10.4 看 learning curve 定位問題

  • Training、validation 都差：可能模型容量不夠、輸入訊號不足、最佳化不佳；先檢查 baseline、loss 定義、梯度與資料。
  • Training 很好、validation 差：可能過度擬合或資料分布不同；考慮正則化、資料量與切分方式。
  • Training loss 持續下降，validation loss 先降後升：典型過擬合訊號，可 early stopping。

講義要求不只報單一數字，還要比較 baseline、畫 training curve、visualize、分析 failure cases、ablation（移除元件看效果）與 gradient。不同模型比較必須使用同樣資料切分、指標與合理訓練條件。

10.5 四種正則化方法

Early stopping：監看 validation，若若干次未改善即停止，並保留 validation 最佳 checkpoint。它降低繼續擬合訓練噪聲的風險，不是保證在任何 overfitting 發生前神奇停止；不能用 test 反覆決定停止時刻。

L2 / Weight decay：以 loss_reg=loss_data+(λ/2)‖w‖²，梯度加 λw。在普通 SGD 下：

w_new=w−η(∇loss_data+λw)=(1−ηλ)w−η∇loss_data

λ 過大可能欠擬合。常不對 bias 加同樣懲罰，因 bias 主要平移，不直接控制輸入敏感度。不要把「權重衰減」理解為每一步每個權重絕對值都必然減少，資料梯度仍可把它推大。

Dropout：訓練時隨機遮蔽部分 activation，減少單元間過度依賴。它可視為訓練共享參數的許多子網路，但一般 test-time 的全網路近似不等於精確平均所有非線性子網路。

令 p=drop probability，q=1−p=keep probability
講義的傳統版本：訓練 ã=m·a，測試用 q 倍貢獻
常見 inverted dropout：訓練 ã=m·a/q，測試直接用 a
m∼Bernoulli(q)，兩種版本不可同時重複縮放

Data augmentation：用合理變換增加訓練樣本的多樣性，例如貓照片小幅平移、翻轉。必須保持標籤語意；數字6上下翻轉可能變9，所以不是任何轉換都安全有效。Augmentation 通常增加有效多樣性，不是減少訓練資料量。

11.1 三組最常考比較

Semi-supervised vs. Self-supervised：前者重點是 labeled/unlabeled 混合；後者重點是目標從資料自動產生。自監督預訓練後可以接監督微調，兩種方法並非互斥。

Active vs. Online：前者問「下一筆該請誰標」，後者問「如何隨新資料逐步更新」。同一系統可同時具備兩者。

Transfer vs. Multi-task vs. Multi-source：分別關注跨任務重用、一起學多目標、結合多輸入來源。可以在同一模型中同時發生。

11.2 強化學習基本循環

Agent 觀察 state s，依 policy 選 action a；環境回傳 reward r 與新 state s'，目標通常是最大化累積回報，而非只貪眼前 reward。RL 在模擬中可做大量試驗，真實世界試驗往往昂貴。這是課堂動機重點，不需要從本資料推定 Bellman equation 等未提供內容必考。

12. 把整門課串起來

看到有標籤的表格分類：先確認切分與評估，再比較樹、NB、k-NN、SVM 或 NN。看到無標籤的分群：先決定距離與尺度，再依群形狀、離群點與是否知道 k 選方法。高維距離無效時可考慮表徵與降維，但降維不得偷看 test。

各方法都在做不同假設：NB 假設條件獨立；k-NN 假設局部相似性有意義；k-means 以平方距離與平均中心描述群；linear SVM 假設線性邊界足夠；NN 透過非線性層組合增加表示力。能說出「資料符合什麼假設、什麼情形會失敗、如何驗證」比背演算法名稱更接近這份考古題要求。

Q2. Naive Bayes Classification（15分；PDF p.1–2）

先判定題目模型

原題提到100封 spam、100封 ham，卻提供詞「出現40次、5次」等計數，文字可讓人誤解為文件出現率。然而公式表明列 multinomial smoothing，且新信為「$$$ $$$ hello」，強調重複次數，因此本解採 Multinomial NB 的 token counts。

詞彙只有2個，|V|=2，不可沿用公式表範例的 |V|=3。每類100封文件只用於理解資料與 prior；Multinomial likelihood 的分母是該類的總詞次。

Q2(a) 平滑後條件機率（5分）

P(w|y)=[count(w,y)+1]/[Σ_v count(v,y)+|V|]
Spam token總數=40+5=45；分母45+2=47
Ham token總數=2+50=52；分母52+2=54
機率正確值
P($$$|Spam)41/47≈0.872340
P(hello|Spam)6/47≈0.127660
P($$$|Ham)3/54=1/18≈0.055556
P(hello|Ham)51/54=17/18≈0.944444

每一類內兩個機率相加為1，這是快速檢查分母的方法。若寫成41/102與6/102，雖像文件發生率，卻不是這題公式表指定的 Multinomial 模型。

Q2(b) 分類「$$$ $$$ hello」（6分）

令 c_$$$=2、c_hello=1。兩類 prior皆0.5，分類分數：

s_S = 0.5 × (41/47)² × (6/47) ≈ 0.0485730522
s_H = 0.5 × (3/54)² × (51/54) ≈ 0.0014574760
ln s_S = ln(0.5)+2ln(41/47)+ln(6/47) ≈ −3.024686
ln s_H = ln(0.5)+2ln(3/54)+ln(51/54) ≈ −6.531049

−3.024686 > −6.531049，因此預測 Spam。小心負數越接近0才越大。

上述為省略共同因素的 log scores，並非已正規化的 log posterior。若另外要求 posterior，可算：P(Spam|x)=s_S/(s_S+s_H)≈0.970868，Ham≈0.029132。題目允許略去兩類共同因子，無須加 multinomial coefficient 3!/(2!1!)；即使加上，分類與 posterior 仍不變。

不連續；跳點為 z=−1、z=1。

這條線為最大 margin 的理由（延伸）：負類凸包最近的一面為 x₁+x₂=1，正類凸包最近點為(1,1)，最近負類凸包點為(0.5,0.5)，兩凸包距離1/√2；最佳分隔線在中間，最大單側距離為1/(2√2)。兩條支撐線是 x₁+x₂=1 和 x₁+x₂=2，完整帶寬1/√2≈0.707107，不是題目要的單側 margin。

縮放 c>0：

  • Functional margins 全部乘 c，因 y(cwᵀx+cb)=c·y(wᵀx+b)。
  • Geometric margins 不變，因 ‖cw‖=c‖w‖，分子分母相消。

Q4(c) 不可分資料如何處理（4分）

原題敘述有誤：「即使資料不可分，hard-margin SVM 仍會找最小誤分類分隔線」不成立。Hard-margin 的約束要求所有點有正的標準 margin；不可分時無可行解。本題原始資料其實可分，但這個一般性說法仍錯。

要求的兩個方法：

  1. Soft-margin SVM：引入 ξᵢ≥0，並使用 C 控制違反 margin 的懲罰，容許某些樣本進入 margin 或被分錯。
  2. Kernel / feature transformation：用非線性特徵空間學線性分隔面，讓原空間的非線性模式有機會被分開；不保證任何資料都可分，必要時仍搭配 soft margin。

C 是懲罰係數，不是直接把不可分資料「變成線性可分」的開關。

Q4(d) 二次 polynomial kernel（5分）

題目的 kernel 常數寫作 C，此處改記 c₀，避免與 soft-margin C 混淆。

K(x,z)=(x₁z₁+x₂z₂+c₀)²
  1. c₀=0：展開為 x₁²z₁²+2x₁x₂z₁z₂+x₂²z₂²，包含原特徵的平方 x₁²、x₂² 與交叉項 x₁x₂。可用 φ₀(x)=(x₁²,√2x₁x₂,x₂²)。
  2. c₀=1：額外出現 2x₁z₁+2x₂z₂+1，所以新增一次特徵 x₁、x₂ 與常數特徵1。可用 φ₁(x)=(x₁²,√2x₁x₂,x₂²,√2x₁,√2x₂,1)。
  3. Kernel trick：SVM 的 dual 與預測只需要樣本間的內積。使用 K(x,z)=φ(x)ᵀφ(z) 直接算內積，就能在豐富特徵空間中訓練／預測，不需明列所有額外特徵。

答案若只寫「升維所以一定可分」缺乏機制且過度保證；應點出「內積替換」與「不必明算 φ」。

Q5. Clustering（5分；PDF p.3）

參考回答：k-means 交替進行指派與更新中心，每步雖不增加平方誤差，但整體問題非凸，可能收斂到不同局部解，因此初始中心不同可造成最終分群不同。可用 k-means++ 初始化，或多次隨機重啟後保留 SSE 最低者，降低不良初始化的影響。

2. 五套手算流程

決策樹

數類別 → 算父熵 → 列各分支計數 → 算各子熵 → 依樣本數加權 → 算增益 → 比大小／交代平手 → 畫節點分布。

合理性：二元熵在[0,1]；純節點熵0；IG不應負。若算負，先檢查分母、log負號與加權。

Naive Bayes

先判定特徵是詞頻、出現與否或一般類別 → 算prior → 正確平滑 → 用詞頻乘log機率 → 加prior → 比較最大score。若要posterior才正規化。

合理性：每類內詞機率加起來為1（Multinomial）；log score通常負，但比較大小要看哪個較大；「$$$ $$$」不能少算一次。

SVM

先把標籤轉±1 → 由直線取w、b → 每點算g(x) → 乘y → 除‖w‖ → 取最小 → 找接觸margin的點 → 清楚註明單側或完整帶寬。

合理性：全分對則signed margin應皆正；同步放大w、b不應改幾何距離；w法向量不能與直線切向量混淆。

Neural Network

先畫連線／確認權重 → 每單元算z → 套activation得a → 算輸出與loss → 從輸出往回算delta → delta乘來源activation得邊梯度 → 全部算完才更新。

合理性：sigmoid輸出在0到1；linear輸出可負；梯度符號應與改善預測方向相符；bias梯度不再乘x。

Confusion Matrix

固定「實際／預測」座標軸 → 寫TP、FP、FN、TN → 分別代入 → 最後比較選項。Accuracy、P、R、F1不共用同一分母。

4. 三種「正則化強弱」別背反

  • 決策樹：最大深度越小、最小葉樣本越大，限制通常越強。
  • L2：在 loss+λ‖w‖²/2 的定義下，λ越大懲罰越強。
  • SVM：在 ‖w‖²/2+CΣξ 下，C越小相對越重視權重正則化。

k-NN 增加k通常使邊界更平滑，但k不是與λ或C完全相同的機制。

5. 申論答題句型

解釋方法：「此方法以＿＿為目標，透過＿＿達成；當資料＿＿時，可能因＿＿失敗。」

解釋過擬合：「模型在訓練資料誤差低，但驗證／測試誤差較高，表示學到部分訓練特有的噪聲；可用＿＿限制複雜度，並用驗證集決定程度。」

解釋kernel：「SVM只需特徵向量內積。以K(x,z)=φ(x)ᵀφ(z)替換內積，就能在豐富特徵空間中學習，不必明列所有φ(x)座標。」

解釋條件獨立：「給定類別後假設特徵獨立；若相關特徵重複提供相同證據，機率可能過度自信，但不一定每次改變類別排序。」

3. 考古題來源與解讀問題

3.1 Q1(a)和Q1(b)計數不同

(a)為4T4F；(b)表格是3T5F，需各自計父熵。即使兩小題的某個資訊增益數值巧合相同，也不能沿用資料。

3.2 Q1(b)三屬性資訊增益平手

Fever、Cough、SoreThroat皆IG≈0.048795。題目未指定平手規則，任一個均可作根。前兩層的意思也可指「根與子節點」或「兩輪切割」；詳解提供兩者，並標類別分布。

3.3 Q2文件數與詞次的混合用語

正文可讓人聯想到Bernoulli，但公式表明列Multinomial，且測試文件含重複詞。本資料採token計數主解，分母分別47、54。Bernoulli若使用文件出現計數才會是102，且重複詞只記一次。兩者不能混搭。

3.4 Q4(c)錯把hard margin描述成可容忍不可分

Hard-margin要求yg≥1，不可分時無可行解。能容忍margin violation的是soft-margin。Kernel能增加表示力，但不能保證任意矛盾資料可分。

3.5 Q6.1(b)「always decreases」過強

加權條件熵不增加，資訊增益可為0；個別子節點熵還可能高於父節點。不能把「不增加」當成「每次嚴格降低」。

3.6 Q6.1(d)同一路徑重複屬性

基本離散完整分支ID3中，屬性一旦已固定，再測無資訊；連續值樹可以用不同閾值切同一特徵。本資料列出兩種解讀，沒有官方解答時不宣稱唯一選項。

3.7 Q6.5(a)early stopping語意

課堂意圖是防止繼續過擬合，通常列為正確；嚴格說依validation判斷與patience無法保證從未發生任何過擬合。本資料將考試慣用理解與嚴格描述分開。

4. 講義中容易過度簡化的地方

  • L2 p.13 的直徑是均方成對距離形式，未必等於2倍半徑，也不是最大點對距離定義。
  • L2 p.35出現「more than MinPts」，其他頁寫「at least」。本文採|Nε|≥MinPts、包含自己；作答先聲明約定。
  • L2 p.41–44的DBSCAN簡化偽碼容易讓人以為非核心點永久是noise；實際擴張後可以改標border。
  • L2 p.62對completeness的中文描述容易被理解成群編號要與類別數字相同。正確定義是同一真實類別集中於同一群，對群編號置換不變。
  • L3-I p.69的「Minimize the number of Support Vectors」是直覺說法。標準SVM的目標是margin／範數與誤差折衷，不是直接最小化支援向量個數。
  • L3-I p.75的bagging提升準確率敘述不應當作每個資料集的保證；模型相關性與資料特性會影響結果。
  • L3-I p.77的0.68256需假設五個模型正確率都0.6，且其判斷獨立；只給平均0.6不足以推得。
  • L3-II p.18的margin對泛化直覺不等於hard-margin對離群值穩健；離群值可大幅影響最大margin邊界。
  • L3-II p.45顯示的kernel預測簡寫容易漏yᵢ。標準α定義下應為ΣαᵢyᵢK(xᵢ,x)+b；若把y吸收進係數才可省略，但係數定義會改變。
  • L4 p.33的universal approximation簡寫不應理解為保證精確表示任意函數；常見結論是在適當條件下任意逼近連續函數。
  • L5 p.32–33用傳統dropout「測試縮放」說明；常見inverted dropout把縮放放在訓練。要選一套一致操作，不能兩次都縮。
  • L5 p.13展示重啟式cosine曲線；單一cosine衰減與warm restarts是不同排程，不能只看名稱推論自動重啟。
  • 講義中的歷史趨勢、產品、網站、軟體範例與法律引述不當作目前狀態的權威資料。本整理聚焦可由講義建立的穩定考試觀念。
